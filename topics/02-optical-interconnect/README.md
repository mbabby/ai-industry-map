# 光通信与光互连｜技术路线、公司分工与关键判断

> 先记住一句话：AI光互连解决的是“很多计算单元如何高效交换数据”。研究时，要分别判断需求是否增长、技术是否量产、哪些公司能留下利润。

整理日期：2026-11-26。状态：初步研究，待讨论。

原始材料：[原始素材｜硅谷101光通信逐字稿](../../notes/原始素材-硅谷101光通信逐字稿-1142b8c3.md)

## 一、这门生意为什么重要

训练大模型、运行部分大模型推理任务，需要多颗GPU共同处理。计算之外，还要在计算单元之间传递数据。网络的带宽、延迟和可靠性，会影响整个任务的效率；不过，具体瓶颈随模型、并行方案、批量和硬件配置变化。

光纤适合承载高速、较远距离的数据传输。随着电信号速率提高，铜连接在损耗、功耗和布线密度上的压力增加，部分连接会更适合使用光。短距离铜连接依然有成本、成熟度和维护优势，不能理解为“一切铜都会被光取代”。

英伟达的CPO技术说明解释了一个关键方向：缩短交换芯片到光电转换器件之间的高速电气路径，降低这段连接带来的负担。[NVIDIA：CPO与能效](https://developer.nvidia.com/blog/scaling-ai-factories-with-co-packaged-optics-for-better-power-efficiency/)

### 三种连接，需求并不相同

| 层次 | 连接什么 | 研究重点 |
| --- | --- | --- |
| Scale-up | 紧密协作的GPU计算域，可在机柜内或跨柜 | 带宽、低延迟、拓扑、内存访问与系统协同 |
| Scale-out | 服务器、计算域之间的集群网络 | 交换机、网络拥塞、光连接数量与成本 |
| Scale-across | 数据中心或更大范围的互连 | 距离、传输容量、光传输系统及传播延迟 |

分类取决于系统架构和通信语义，不能只用“机柜内、机柜外”划线。数据中心之间接上光纤，也不意味着可以无成本地组成同一台低延迟超级计算机。

## 二、先把两组技术分类分开

这是理解原稿最重要的一步。

### 第一组：光信号怎么产生和调制

| 路线 | 通俗理解 | 要注意什么 |
| --- | --- | --- |
| EML | 把激光器和电吸收调制器集成，让光承载数据 | 高速激光器的设计、制造、良率与可靠性很重要 |
| 硅光 + CW光源 | 由连续波激光器提供光，再由硅光芯片调制、传输和接收 | 硅光没有自动消除对高质量激光器的需求 |

EML通常把DFB激光器与电吸收调制器集成在同一芯片上；“硅光 + CW”是这里为便于理解采用的简化描述，并非光通信全部技术路线。[Lumentum：EML产品](https://www.lumentum.com/en/optical-communications/products/source-lasers-ics-and-photodiodes/emls)

### 第二组：光电转换放在哪里

| 形态 | 放在哪里 | 主要取舍 |
| --- | --- | --- |
| 可插拔 | 设备面板上的独立模块 | 更换方便、生态成熟；高速电气路径和面板密度面临压力 |
| NPO | 光引擎靠近交换芯片，但通常保留较强模块化 | 缩短电气路径，同时兼顾装配和维护 |
| CPO | 光引擎与交换芯片等进行共封装 | 更紧密集成，考验封装、散热、良率、测试和维修 |

**硅光不等于CPO。** 硅光也能用于可插拔模块。Lumentum明确提供用于硅光可插拔收发器的CW激光器，因此不能把“EML→硅光→CPO”画成一条必然替代路线。[Lumentum：硅光收发器CW激光器](https://www.lumentum.com/en/products/data-center/cw-lasers/cw-lasers-sipho-transceivers)

LPO主要改变信号处理方式，通常仍是可插拔形态；它也不是NPO之前必经的“距离阶段”。更多高密度可插拔设计，应按具体产品的接口、散热与量产状态逐项比较。

## 三、沿着一条光连接拆产业链

简化链路：电数据 → 驱动/信号处理 → 激光与调制 → 光纤传输 → 探测与接收 → 电数据。

真实产品的集成方式会改变各环节边界；某些线性方案不配置传统模块DSP。

| 环节 | 产品与工作 | 原稿涉及的代表企业 | 真正需要研究的能力 |
| --- | --- | --- | --- |
| 材料与外延 | 磷化铟等衬底、外延晶圆 | IQE等 | 缺陷控制、一致性、良率与扩产周期 |
| 激光器与光芯片 | EML、CW激光器、探测器等 | Lumentum、Coherent等 | 功率、效率、可靠性、高速性能与产能 |
| 电芯片与光电平台 | DSP、驱动/TIA、SerDes、硅光等 | Broadcom、Marvell等 | 系统适配、信号完整性、设计与客户认证 |
| 精密器件与光引擎 | 耦合、光纤阵列、光器件及封装 | 天孚通信等 | 精密制造、自动化、良率和稳定交付 |
| 光模块 | 把光电部件做成客户可部署的产品 | 中际旭创、新易盛等 | 产品设计、集成、测试、认证及大规模交付 |
| 交换与系统 | 把连接装进网络和整套计算系统 | NVIDIA、Broadcom及设备商 | 架构、接口、软硬件协同和客户关系 |
| 终端采购与使用 | 云厂商、数据中心运营者等 | 客户按部署场景变化 | 系统总成本、供应稳定性与运维 |

表中是研究起点，不是完整供应商名单、市场份额排名或“所有业务已进入该客户”的证明。同一家企业可能跨多个环节。

天孚通信的官方展示覆盖光引擎、光学耦合封装、光纤阵列等，不能简单理解为低技术含量的组装。模块厂也承担研发、可靠性和量产工作，不能仅按产业链上下游判断技术价值高低。[天孚通信：ECOC 2025产品展示](https://www.tfcsz.com/en/news/1009.html)

IQE同时展示衬底和外延业务，研究公司时应按具体产品确认角色。[IQE：产品](https://www.iqep.com/products/)

## 四、CPO可能改变谁的生意

**事实层面：** CPO让光引擎靠近高功耗交换芯片。外置光源是一种实际产品方案，把光源通过光纤连接到光引擎，便于处理热与维护问题。[Lumentum：外置光源](https://www.lumentum.com/products/external-laser-source-els-module-ultra-high-power-laser)

**我的初步推论：** 当原来装在光模块里的功能被拆到系统不同位置，采购边界可能变化。系统厂可能直接购买更多光引擎、光源和封装服务，模块厂的部分价值也可能迁移。

但“可插拔外壳减少”不能直接推出“模块厂的价值归零”。要继续看：

- 模块厂能否进入光引擎、CPO集成或新型可插拔产品？
- 原来的客户认证、量产能力、测试经验能否延用？
- 谁负责系统集成和故障处理，谁承担不良率与返修成本？
- 同一个系统，采用CPO后节约的成本，有多少留给供应商？

同样，激光器需求增加，也不等于激光器厂一定长期保持高利润。竞争、客户集中、技术迭代和扩产后的供需变化都可能改变结果。

## 六、现在可以形成什么判断

**判断一：光通信值得作为AI产业链的独立板块研究。** 多GPU协作带来真实的连接需求，但具体需求量要由网络架构、端口速率、连接数和部署规模共同决定。

**判断二：光靠近芯片的方向，有清楚的工程动因。** 具体何时切换、哪些场景先切换，还要算系统成本，并验证可靠性和维护便利性。

**判断三：这轮变化的重要影响，是供应链的重新分工。** 值得研究谁把光电转换做得更靠近芯片，以及谁能承担相应的系统责任。当前不能仅凭“CPO概念”给企业排赢家。

**判断四：方向正确与回报良好是两回事。** 提前扩产可能遇到客户项目延期，旧产品利润也可能因新路线加快而下滑。持续增长仍可能低于此前预期。

## 七、后续观察什么

| 要验证的问题 | 优先找的证据 |
| --- | --- |
| 需求是真实落地还是只在规划 | 客户已通电项目、实际交付与验收、资本开支执行 |
| CPO是否具备规模部署能力 | 付费出货、客户部署数量、良率、寿命、故障维修记录 |
| 模块厂能否保留价值 | 新产品收入、客户认证、光引擎/CPO相关量产证据 |
| 上游紧缺能维持多久 | 实际产能、扩产进度、交付周期、可取消订单比例 |
| 更高速度是否带来更高利润 | 单位成本、产品售价、研发和折旧、产品毛利变化 |
| 政策如何改变供应链 | 正式规则、实施时间、产品和产地的具体适用条款 |

## 八、我们接下来讨论的三个问题

1. 先从客户算账：如果继续用铜或可插拔，代价究竟增加在哪里？
2. 再从供应链算账：CPO改变产品形态后，谁获得新工作，谁失去原来的工作？
3. 最后从企业算账：这些工作是否难以替代，利润能否覆盖研发、扩产和风险？

建议先谈第二个问题。它能把激光器、模块厂与系统厂放到同一张图里，也最有助于理解“技术趋势很好，为什么不同公司结局可能完全不同”。
