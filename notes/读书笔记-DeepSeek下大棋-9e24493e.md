# 读书笔记｜DeepSeek下大棋

> 学习归档：保留来源陈述、讨论与原有核验边界；不是对所有事件和数据的重新确认。涉及公司、价格、政策和产品状态，请按原记录日期阅读并回查来源。

记录于 2026-11-17。来源为用户提供的蔡钰《商业参考 5》讲稿《DeepSeek下大棋》。以下整理讲稿的论证，企业动向与数字按原文归属记录，未经独立核验。

## 一句话总结

蔡钰把融资、算力建设、开源、产品整合和国产芯片预训练放在一起看，提出一个判断：DeepSeek 可能正从研发和提供模型，走向组织算力、软件与应用的协同。

## 原文的五个动作

| 动作 | 原文说法 | 在论证中的作用 |
| --- | --- | --- |
| 融资与控制权 | 2026 年两轮融资分别超过 500 亿元和达 1,055 亿元，估值约 3,500 亿和 6,155 亿元。原文称第二轮国资占比从首轮约 2% 升至 27%，梁文锋仍掌握超过 75% 股权和接近全部表决权 | 作者将资金规模与投资者构成解读为建设算力、协调上下游的准备 |

## 我的提炼

**1. 自建算力要算长期使用率。** 训练集中发生，推理则随日常调用持续发生。Agent 如果要反复调用模型并执行多个步骤，可能拉长单次任务的计算过程。自建有没有优势，要看需求能否长期填满产能，还要算电力、运维、折旧和闲置成本。

**2. 开源可以扩大使用，官方 API 仍有机会赚钱。** 原文用腾讯 WorkBuddy 据称采用官方 API 的案例解释：即使能自行部署，企业仍要承担适配、运行和维护成本。官方服务能否留下客户，需要同口径比较价格、延迟、可靠性与维护成本。客户愿意用 API，也不能单凭价格倒推出供应商的盈利水平。

**3. 投资者阵容只是合作线索。** 运营商、芯片及存储企业、储能企业和应用平台各自能提供不同资源。要判断 DeepSeek 是否真能组织起这条产业链，应继续看合作是否进入可验收的部署、训练或长期采购，以及谁承担投入和运行风险。

## 引用前核实

- **融资与上市**：查公司或投资方披露、工商股权变更及监管辅导备案。区分融资意向、已交割金额、直接或间接持股、表决权，以及上市准备。原文的中信证券辅导和招聘 CFO 属消息说法。
- **乌兰察布项目**：招聘是项目线索。核对 1 吉瓦是规划规模、获批用电还是建成容量，16 万颗芯片是规划、采购还是实际部署。
- **开源与产品**：查官方公告、代码仓库、许可证及版本日志，分别确认 DeepInfer、Super-agent、V4.1 Flash 和 Harness 的名称及发布状态。组织调整另需可靠来源。
- **预训练与成本**：把计划、试验和完成完整预训练分开。原文引述的 5 万颗 GB300 对比 20 万颗昇腾 950 是待核实估算，不能据此认定性能或成本恰好相差四倍。核对模型、训练目标、集群互联、完训时间与总成本。
- **WorkBuddy 与推理经济性**：查《财经》原报道及产品文档，确认是否经官方 API 调用、适用版本及原因。原文的电价、芯片定制、行业 GPU 利用率 25% 和接近满载等说法，均需核对来源与测算口径。
- **历史基线**：原文用“轻资产、主要租算力”概括 2026 年以前，需要核实 DeepSeek 和幻方既有算力资产的归属与使用关系。
