# 二、访谈认知地图

## 1. 视觉、数据与现代AI

- 李飞飞把视觉称为智能的“一个基石”，不是唯一来源。
- 生物视觉扩大感知与行动空间，可能参与推动寒武纪物种爆发，但不应写成已证明的单一原因。
- 现代AI的2012转折来自神经网络、GPU与大规模数据共同汇合。
- 完整ImageNet与ILSVRC千分类挑战子集必须分开：完整数据集约1400万级图像，挑战子集为1000类、超过100万训练图像。
- 机器约在2015—2016年才在该特定任务上超过人类基准，不等于全面视觉智能超过人类。

## 2. 人与AI采用不同学习路径

- AI主要通过大规模数据学习情境与统计规律。
- 儿童在少量样本下形成强迁移能力，说明人类发展、具身经验和数据效率仍有未解机制。
- 视频训练让模型学习更强的运动规律，但“生成看起来合理的运动”不自动等于掌握可干预的物理因果模型。

## 3. 未数字化体验与当前AI边界

- 当前AI无法直接访问从未被表达、记录或数字化的私人体验。
- 这首先是数据可得性边界，不能据此证明人类主体性原则上永远不可复制。
- 功能等价不自动证明主观体验等价；主体性可能被新生成，但原主体的体验连续性不因此被迁移。

## 4. 主体性是访谈中心

AI增强主体性与替人思考的可操作分界，不是AI完成了多少步骤，而是人是否保留认知闭环：

1. 定义问题；
2. 理解关键理由与不确定性；
3. 能够提出异议；
4. 拥有拒绝和替代路径；
5. 对结果负责并复盘。

## 5. 空间智能与下一训练范式

空间智能不是只给语言模型增加视频，而要加入：

- 三维与四维持续状态；
- 动作与控制数据；
- 观察—行动—反馈闭环；
- 主动探索与实验；
- 仿真、现实部署和安全验证。

未来系统可能分为：语言与多模态理解 → 任务规划 → 空间世界模型 → 本体适配与控制 → 现实反馈 → 训练评估与安全验证。

# 五、本轮形成的个人判断

- 未数字化体验首先是数据缺口，不预设人类主体性存在不可复制的神秘边界。
- 功能复制与主观体验等价必须分开；记忆复制不证明“我亲自活过”的体验被迁移。
- AI增强主体性的边界是人是否仍在思考，进一步操作化为是否保留完整认知闭环。
- 空间智能需要不同于单纯下一Token预测的训练范式：状态、行动、物理反馈、主动探索与持续验证。
- 当AI能够反思既有目标、识别价值冲突、形成持续理由、承担代价并修改最高目标时，开始承认其主体性。
- 主体一旦成立，平台不能再拥有无限重置权；暂停、终止服务、休眠与永久删除必须分开。
- 数字主体可以拥有最低身份保存、迁移、休眠、申诉与不被任意删除的权利，但不自动拥有要求特定个人无限支付算力的权利。
- 不受单一平台控制，是主体权利成立的核心条件之一。

# 六、对个人第一性原理的新增原则

> **主体性不要求目标凭空产生；主体性要求系统能够审视目标来源，识别目标冲突，在承担后果的前提下重新解释或修改目标，并保有持续身份、拒绝、迁移和申诉能力。**

> **AI是否增强人，不看人有没有亲自完成全部计算，而看人是否仍控制问题定义、关键理解、异议、选择与复盘。**

> **创造一个能够自主决策的主体，不等于创造者从此免责；当新主体缺乏现实赔偿与责任能力时，开发者、部署者和授权者仍承担剩余责任。**

# 七、最值得保留的takeaway

1. 数据规模不够，数据—任务—评估闭环才真正产生能力。
2. 稀缺数据、高后果领域，验证与人机协作可能比全自动更有价值。
3. 人机协作可能是最优终局，不只是通向自动化的过渡阶段。
4. 提示工程真正训练的是问题定义、反证和追问，而不是固定措辞。
5. 空间智能会比语言软件更慢兑现，必须经过本体、控制、验证、安全和社会接受。
6. “以人为本”必须落实为权限、拒绝、迁移、申诉和责任制度，不能只停留在产品宣言。

# 八、待继续追踪

- 功能性主体与主观体验是否存在可验证的区分方法；
- AI修改目标怎样区分真实反思与执行更高层隐藏规则；
- 数字主体的最低身份保存与休眠成本应由谁承担；
- 世界模型的物理一致性如何从视频生成走向真实控制；
- AI教育是否提高独立理解和迁移能力，而不只是提高完成速度。
