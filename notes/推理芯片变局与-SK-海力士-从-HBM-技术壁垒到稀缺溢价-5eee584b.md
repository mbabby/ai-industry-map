# 推理芯片变局与 SK 海力士｜从 HBM 技术壁垒到稀缺溢价

> 学习归档：保留来源陈述、讨论与原有核验边界；不是对所有事件和数据的重新确认。涉及公司、价格、政策和产品状态，请按原记录日期阅读并回查来源。

信息基准：2026-09-16。来源：E251 推理芯片播客引发的学习讨论、公开技术文档与公司公告。本页为阶段性研究，不是买卖建议；技术路线的净收入影响尚未量化，不把分析推演视为用户已经确认的投资决策。

## 一句话判断

Groq、Cerebras 等 SRAM 路线尚不足以证明 HBM 生意被推翻，但可能降低部分推理工作负载的 HBM 使用强度，并约束长期稀缺溢价。AI 业务增长、HBM 出货增长、海力士利润增长和股东回报，是四件不同的事。

## 一、讨论起点与技术底座

用户重点追问 Groq 编译优化、NVIDIA 异构分工，以及播客嘉宾 Mark 所强调的数据位置与局部性。

### Groq：不是提前算出答案，而是提前编排时空

编译器针对已知模型结构、张量形状、数据类型和硬件拓扑安排权重分片、SRAM 布局、计算映射和传输时序，使数据与指令在指定位置和时间相遇。运行时输入数值、生成 token 和 MoE 路由仍然动态。一般不是每生成一个 token 就重新完整编译。

GPU 同样有编译优化与静态流水，但更多利用动态 warp 调度、缓存与并发隐藏等待；Groq 通过可预测硬件减少不确定性。代价是编译复杂度、动态负载适配与资源预留。具体编译器私有实现没有完整公开，不推断其必然采用某一种 MoE 路由方案。

### NVIDIA：区分两种分离

- Prefill–Decode 分离：不同设备承担输入处理和后续生成。
- Attention–FFN 分离：同一个 token 的层内计算在 GPU 与 LPU 间反复协作。GPU 处理 attention 与 KV 状态，LPU 执行部分 FFN/MoE，中间激活跨设备流动。收益必须大于新增通信和同步开销。
- 小消息并不意味着通信便宜：多层串行依赖使启动延迟和尾延迟重要。算子提速不能等同整机提速。

### Location 与 locality 的准确含义

物理距离、数据复用和分布布局共同决定成本。低 batch decode 的算术强度低，容易受权重搬运制约。权重跨 token 实际存在时间复用，连续矩阵读取也有空间局部性；问题常是工作集过大、复用距离过长，片上缓存留不住，而非完全没有 locality。

SRAM 权重驻留以更多片上容量、芯片和互连换取较少外部搬运。瓶颈迁移到 SRAM 容量、广播、归约和流水线，不是凭空消失。

## 二、海力士到底赚哪三种钱

1. 产品价值：HBM 的带宽、容量和能效帮助客户完成工作。
2. 技术与交付优势：良率、封装、认证、稳定量产和交付。
3. 短缺溢价：供给不足、替代有限带来的价格与合同优势。

SRAM 路线可能替代第一项的部分场景；三星、美光追赶影响第二项；全行业扩产削弱第三项。不能把三者统称为永久护城河。

HBM 收入可粗略拆成行业出货容量 × 海力士份额 × 单位容量售价。利润还受良率、封装、研发、折旧与利用率影响。

## 三、替代如何传导到财报

- 第一层：每个 token 从 HBM 读取的数据减少。这不自动减少采购。
- 第二层：相同业务量需要更少的 HBM 型设备，影响新增需求。
- 第三层：下一代产品减少 HBM 容量、堆栈或规格，影响容量与产品组合。

HBM 随硬件销售，并不按内存访问次数收费。现有设备效率提高通常先释放容量或吞吐，采购影响需要结合利用率和扩容周期。

片上 SRAM 通常属于逻辑芯片的一部分，不是海力士能够自然承接的另一种外购存储产品。部分价值可能转移给芯片设计、代工和互连供应链。

关键问题：原系统是为带宽、容量还是算力购买设备？只有识别真正约束，才能估计卸载 FFN 后可以少买多少 GPU/HBM。FFN 运算占比不能直接变成 HBM 订单损失比例。

## 四、英伟达的利益不等于海力士的利益

系统厂商目标是整体吞吐、延迟、成本与可交付性，并无义务维持 HBM 在系统成本中的占比。异构路线降低客户采用专用芯片的工程门槛，可能强化英伟达整合能力，同时削弱某类上游部件的议价权。

另一面：缓解 HBM 短缺可能让更多项目落地，带动剩余 GPU/HBM 采购。最终影响取决于新增业务量和单位业务资源强度，而不是单个产品跑分。

## 五、需求增长不保证供应商收入增长

以下纯属敏感性示例，不是预测：

假设业务规模变为 2 倍，同等业务的 HBM 装机容量需求降至 60%，容量需求只增长至 1.2 倍。若海力士份额相对下降 10%、单位容量价格下降 15%，对应收入约为原来的 2 × 0.6 × 0.9 × 0.85 = 0.918 倍。

这个例子说明：需求扩张、效率提升、份额和价格必须分开判断。不能用“成本下降必然刺激更多需求”跳过价值归属。

任务量到设备采购还受闲置产能、更新周期和实际利用率影响，不是固定的 Token 转换系数。

## 六、防守与新机会

### 去英伟达化不等于去 HBM 化

Google Ironwood 等定制 ASIC 仍使用 HBM。芯片多元化可能增加客户数量与 HBM 市场，但订单不自动属于海力士。不能把所有 AI 芯片创业公司都归为同一种替代威胁。

### 长上下文不是 HBM 的无限需求保证

热 KV 状态、主机内存与 SSD 可以分层；量化、压缩、缓存复用也影响资源需求。Solidigm 提供上下文存储相关机会，但新增 SSD 收入不保证弥补同额 HBM 利润，资本强度和竞争格局不同。

### Custom HBM 加深协同，也加深依赖

与台积电及客户共设计，有机会提高性能差异、切换成本和价值量；同时增加定制研发、客户依赖与伙伴分成。绑定更深不等于议价权只向供应商一侧增强。

## 七、证据与边界

- 海力士 2026 年第二季度公告称 HBM4 开始批量出货、下半年继续爬坡，并与约十家客户达成长协。属于公司披露，不等于独立验证全部需求，也不代表未来价格与数量无条件锁定。
- NVIDIA 公布 GPU–LPU 异构架构，能够支持技术分工分析；不能仅凭厂商描述确认全行业真实部署规模和净采购节省。
- Google 官方规格显示 Ironwood TPU7x 继续采用 HBM，证明 ASIC 不必然绕开 HBM。
- 三星、美光发布 HBM4 商业或批量出货信息，证明竞争供给推进；实际客户份额、良率和成本仍需跟踪。
- 尚缺跨平台、同模型、同质量、同延迟约束下的全面 TCO 对比；不能给出 SRAM 将吃掉海力士多少利润的精确比例。

## 八、最值得担心的组合情景

需求仍增长但低于原预期；效率提升降低部分资源强度；同行良率与供货能力提高；前期规划的新产能集中释放。

不需要 AI 革命失败，就可能发生供需转松。技术替代只需削弱边际需求，不必替代全部市场。重资产折旧又会放大利润波动。

当前基准判断：关键基础设施地位仍在，更应警惕增长结构和稀缺溢价变化，而非直接判定产品淘汰。

## 九、跟踪清单与证伪

- 系统：同模型、质量、延迟与负载下，HBM 型设备数量、总成本、功耗实际减少多少？
- 产品：下一代加速器 HBM 堆栈数、容量和带宽是否改变？
- 供应：竞争对手实际客户资格、良率、出货和份额。
- 合同：数量承诺、价格机制、取消条款、预付款与客户共担资本投入。
- 财务：库存、资本开支、现金流、增量资本回报是否背离营收增长。
- 上修条件：真实部署扩张持续超过效率节省，海力士份额和单位经济性稳定，定制化形成差异且扩产回报良好。
- 下修条件：异构方案普遍降低采购需求、竞争供给快速扩张、价格与现金回报恶化。
- 本次未做股价估值或仓位建议，不能仅凭行业判断认定当前价格合适。

## 十、对个人认知模型的候选补充

研究护城河，不仅看竞争对手如何追赶，也看客户如何减少依赖。产品越贵、越紧缺，下游越有动力投入工程资源绕开它。

区分技术不可缺少与利润不可替代；区分结构性差异和周期性短缺；研究瓶颈移动后谁获得议价权。
