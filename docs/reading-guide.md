# 如何读这份产业地图

## 按问题进入

| 想弄清的问题 | 优先板块 |
| --- | --- |
| GPU 更强了，为什么整体效率仍受限？ | 计算、存储与制造；光通信与光互连 |
| 算力需求很大，为什么项目仍会延期或亏损？ | 电力、数据中心与云；产业竞争、资本与治理 |
| 模型之外还有什么值得研究？ | 数据、仿真与评测；Agent 与基础软件 |
| 客户为什么愿意持续付费？ | 应用与行业交付；端侧 AI 与智能硬件 |
| 机器人供应商怎样和本体公司合作？ | 具身智能与机器人；数据、仿真与评测 |

## 四层判断分开做

1. **需求**：谁需要什么结果？现有方案哪里不够好？
2. **技术**：新路线解决了什么，又增加了什么成本和限制？
3. **经营**：谁能交付，谁承担风险，利润怎样留下？
4. **价格**：企业价值与购买价格相比较，是否值得承担风险？

前一层成立，不代表后一层自动成立。项目以学习研究为主，不提供统一的公司排名或交易信号。
