## 脱敏处理

- 隐去本地文件路径、凭证样式字符串、网络地址及个人公众号名称。
- 私人工作区链接改为仓库内相对链接；未纳入本项目的内部关联保留名称，不保留访问地址。
- 去除 PDF、PNG 中的可移除元数据；检查扫描版 PDF 中的文字与二维码。
- PDF 中发现的二维码和联系方式区域使用实际内容删除处理，不是叠放一块可移除的遮挡图。
- 原始导出缓存、带签名下载地址、OCR 中间结果和脱敏前附件不纳入仓库或提交历史。
- Git 提交使用 GitHub 提供的 noreply 邮箱，避免公开私人邮箱。

保留公开演讲者与公司名称，用于正确归属来源。个人讨论经过处理后保留产业观点，不把它们转成作者、嘉宾或公司的正式承诺。
